# วิทย์ ท่าเรือ — แกลเลอรีพระเครื่อง

เว็บ: https://wittharua.netlify.app

- `site/index.html` — หน้าเว็บทั้งหมด (Netlify เผยแพร่โฟลเดอร์ `site`)
- `apps-script/Code.gs` — สำเนาโค้ด Google Apps Script หลังบ้าน (ตัวจริงอยู่ใน Google Sheet → ส่วนขยาย → Apps Script)
- ข้อมูลพระอยู่ใน Google Sheet ไม่ได้อยู่ใน repo นี้

การแก้เว็บ: แก้ใน branch แยก แล้วเปิด Pull Request เพื่อดูตัวอย่าง (Deploy Preview) ก่อน รวมเข้า `main` เมื่อต้องการขึ้นเว็บจริง
